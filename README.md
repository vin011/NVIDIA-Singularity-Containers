# Welcome

## Overview
- `sif_files`: compressed sif files
- `examples`: example batch scripts for specific supercomputers
- `docs`: documentation of the available files and creation processes

### Using Sif File
1. Clone the repo
2. Decompress the sif files with `tar -xzvf <sif_file>.gz`
3. Ensure singularity or apptainer is currently running
4. Load and compute
