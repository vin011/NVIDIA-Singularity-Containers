# Usage
- To run one command: `singularity exec tensorflow_XXXXX.sif <command>`
  Ex: `time -p singularity exec --bind /expanse,/scratch --nv tensorflow_25.01-py3.sif python3 ../examples/tensorflow_25-gpu.py`
- To launch interactive container: `singularity run tensorflow_XXXXX.sif`

# Notes
- `time -p` measures how long a command takes to execute in seconds. Referring the example output below, `real` is the total elasped time, `user` is CPU time spent running processes aka user-time, `sys` is CPU time spent running system calls aka kernel-mode.
```
real 195.70
user 179.70
sys 8.97
```
- In the provided examples, it may be neccessary to change the module versions
